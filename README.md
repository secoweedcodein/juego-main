## Cómo ejecutarlo en tu PC

Necesitas Node.js 20 o superior (recomendado instalarlo con [nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
git clone <url-de-tu-repositorio>
cd <carpeta-del-repositorio>
npm install
npm run dev
```

Luego abre `http://localhost:8080` en Chrome, Edge o Firefox (necesita WebGL activado).

Para generar la versión optimizada:

```sh
npm run build
npm run start
```
